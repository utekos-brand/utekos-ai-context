# Canva documentation URL skeleton

This structure mirrors the paths referenced in Canva's official [Apps](https://www.canva.dev/docs/apps/llms.txt) and [Admin](https://www.canva.dev/docs/admin/llms.txt) documentation indexes.

- 550 distinct local documentation paths mapped
- 549 new path placeholders prepared
- 1 existing path files retained unchanged
- 7 non-document URL references included in the manifest

Newly added Markdown files contain only the official source URL and an explicit placeholder notice; they are **not copies of the full documentation**.

See [`canva-url-manifest.json`](./canva-url-manifest.json) for every mapped source URL, local path, and whether a file was created or already existed. Original index: [`apps/llms.txt`](./apps/llms.txt). Existing `admin/llms.txt` was preserved.
