# Folders

The Canva REST APIs for managing folders.

The `folders` endpoint enables you to create, edit, update, delete, and manage folders in a user’s Canva library.

Use folders to organize your library content in a structured way. Folder names can make the library more readable and searchable.

The top level of the user's content library is represented by the folder with the ID `root`. The user's Uploads folder is represented with the ID `uploads`.

For more information about Canva folders, see [Canva concepts](https://www.canva.dev/docs/apps/canva-concepts/#folders).

## Folders APIs

* [Create folder](https://www.canva.dev/docs/apps/rest-apis/reference/folders/create-folder/): Create a new folder in the user's [**Projects**](https://www.canva.com/help/find-designs-and-folders/).
* [Get folder](https://www.canva.dev/docs/apps/rest-apis/reference/folders/get-folder/): Retrieve a folder's metadata.
* [Update folder](https://www.canva.dev/docs/apps/rest-apis/reference/folders/update-folder/): Update a folder's metadata.
* [Delete folder](https://www.canva.dev/docs/apps/rest-apis/reference/folders/delete-folder/): Delete a folder.
* [List folder items](https://www.canva.dev/docs/apps/rest-apis/reference/folders/list-folder-items/): List the contents of a folder.
* [Move folder item](https://www.canva.dev/docs/apps/rest-apis/reference/folders/move-folder-item/): Move an item from one folder to another.
