# Scopes

The `scope` parameter specifies the types of access that your integration needs for a user's account. The list of possible scopes used in the Admin APIs are shown below:

```
<table>
  <thead>
    <tr>
      <th>Scope</th>
      <th>Description</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>`admin:auditevent:read`</td>
      <td>List audit events for the Canva organization.</td>
    </tr>

    <tr>
      <td>`admin:group:read`</td>
      <td>Read information about a Canva group.</td>
    </tr>

    <tr>
      <td>`admin:group:write`</td>
      <td>Create or modify a Canva group, and add or remove its users.</td>
    </tr>

    <tr>
      <td>`admin:organization:read`</td>
      <td>Read information about the Canva organization.</td>
    </tr>

    <tr>
      <td>`admin:team:read`</td>
      <td>Read information about a Canva team and its users.</td>
    </tr>

    <tr>
      <td>`admin:team:write`</td>
      <td>Create or modify a Canva team, and add or remove its users.</td>
    </tr>

    <tr>
      <td>`admin:user:read`</td>
      <td>Read information about a Canva user.</td>
    </tr>

    <tr>
      <td>`admin:user:write`</td>
      <td>Create a managed user in the organization.</td>
    </tr>
  </tbody>
</table>
```
