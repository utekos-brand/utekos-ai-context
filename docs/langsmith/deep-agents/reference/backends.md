# Backends

> deepagents → Backends

Backends control how deep agents store files and manage state.
Choose a backend based on your persistence and isolation
requirements.

> **Learn more:** For detailed guidance on choosing and
> configuring backends, see the
> [Backends documentation](https://docs.langchain.com/oss/javascript/deepagents/backends).
