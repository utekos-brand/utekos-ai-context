# Use the Data Manager API to manage audiences for Google Ads

- **Google Ads:** [Customer Match audiences using contact information or user
  IDs, and mobile device ID audiences](https://developers.google.com/data-manager/api/devguides/audiences/google-ads/customer-match).

The Data Manager API uses [confidential
matching](https://support.google.com/google-ads-data-manager/answer/14577185) to
process Customer Match data and supports
[encryption](https://developers.google.com/data-manager/api/devguides/concepts/encryption).
