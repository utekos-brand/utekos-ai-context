### Customer and audience fields

The Google Ads API supports uploading audience members to **one audience per job**. It requires the `developer-token` header and uses `login-customer-id` and `linked-customer-id` headers for authentication scenarios.

The Data Manager API supports [multiple audiences in a single request](https://developers.google.com/data-manager/api/devguides/audiences/send-audience-members#multiple-destinations). It does not require a developer token. Instead, login and linked customer information are specified within a `Destination` object. See [Configure destinations](https://developers.google.com/data-manager/api/devguides/concepts/destinations).

The Data Manager API does **not** support removing all audience members. In the Google Ads API, this is done by setting `remove_all = true` in an [`OfflineUserDataJobOperation`](https://developers.google.com/google-ads/api/reference/rpc/latest/OfflineUserDataJobOperation).

### User identifier fields

In the Google Ads API, all identifiers use [`UserIdentifier`](https://developers.google.com/google-ads/api/reference/rpc/latest/UserIdentifier).\
The Data Manager API separates identifiers by type.

Use the appropriate field depending on data type:

- [Contact information](https://developers.google.com/data-manager/api/devguides/audiences/google-ads/customer-match/upgrade/field-mappings#contact-information)
- [Mobile IDs](https://developers.google.com/data-manager/api/devguides/audiences/google-ads/customer-match/upgrade/field-mappings#mobile-ids)
- [User IDs](https://developers.google.com/data-manager/api/devguides/audiences/google-ads/customer-match/upgrade/field-mappings#user-ids)

If using contact information (email, phone, address), set `composite_data` with entries in `user_data.user_identifiers`.

Although [`user_data`](https://developers.google.com/data-manager/api/reference/rpc/google.ads.datamanager.v1#google.ads.datamanager.v1.AudienceMember.user_data) is supported, using [`composite_data`](https://developers.google.com/data-manager/api/reference/rpc/google.ads.datamanager.v1#google.ads.datamanager.v1.AudienceMember.composite_data) is recommended for future compatibility. See [Composite data](https://developers.google.com/data-manager/api/devguides/audiences/send-audience-members#composite-data).

#### IP address

The Data Manager API supports IP address ingestion via [`CompositeData`](https://developers.google.com/data-manager/api/reference/rpc/google.ads.datamanager.v1#compositedata), combining [`UserData`](https://developers.google.com/data-manager/api/reference/rpc/google.ads.datamanager.v1#userdata) and [`IpData`](https://developers.google.com/data-manager/api/reference/rpc/google.ads.datamanager.v1#ipdata).

Including IP data can improve match rates.

See [IP ingestion for Customer Match](https://developers.google.com/data-manager/api/devguides/audiences/send-audience-members#send-ip-timestamp).

**Note:** Improvements from IP signals are expected starting Q3 2026.

| Google Ads API     | [`CompositeData`](https://developers.google.com/data-manager/api/reference/rpc/google.ads.datamanager.v1#compositedata) (Data Manager API) | Notes                                                                                                                |

| No equivalent      | `ip_data.ip_address`                                                                                                                       | Raw IPv4 or IPv6 address                                                                                             |
| No equivalent      | `ip_data.observe_start_time`                                                                                                               | RFC 3339 timestamp                                                                                                   |
| No equivalent      | `ip_data.observe_end_time`                                                                                                                 | RFC 3339 timestamp                                                                                                   |
| `user_identifiers` | `user_data`                                                                                                                                | Set as [`UserData`](https://developers.google.com/data-manager/api/reference/rpc/google.ads.datamanager.v1#userdata) |
